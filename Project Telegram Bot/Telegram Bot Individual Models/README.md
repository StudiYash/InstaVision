# 🎨 InstaVision Bot Project - Individual Models

Welcome to the **InstaVision Bot Project**! This repository contains the code for each model used in the InstaVision Bot as individual folders, making it easy for users to explore and experiment with specific models.

---

## 📂 Individual Models Folder

Each folder corresponds to a specific API integrated into the InstaVision Bot. Here's an overview:

1. **`InstaVision Bot (Dall E3 API)`**
   - This folder contains the complete implementation of the InstaVision Bot using the **DALL-E 3 API** for high-quality and detailed image generation.

2. **`InstaVision Bot (Flux Schnell API)`**
   - Explore the power of **Flux Schnell**, a highly efficient API for generating images quickly without compromising quality.

3. **`InstaVision Bot (Google Imagen3 API)`**
   - This folder showcases the integration of the **Google Imagen 3 API**, providing exceptional image clarity and vibrant visuals.

4. **`InstaVision Bot (Sdxl Lightning 4Step API)`**
   - Dive into the **Sdxl Lightning 4Step API**, known for its ability to create stunning images with a streamlined approach.

---

## 🔧 How to Use

1. Navigate to the folder of your choice:
   - [InstaVision Bot (Dall E3 API)](./InstaVision%20Bot%20(Dall%20E3%20API))
   - [InstaVision Bot (Flux Schnell API)](./InstaVision%20Bot%20(Flux%20Schnell%20API))
   - [InstaVision Bot (Google Imagen3 API)](./InstaVision%20Bot%20(Google%20Imagen3%20API))
   - [InstaVision Bot (Sdxl Lightning 4Step API)](./InstaVision%20Bot%20(Sdxl%20Lightning%204Step%20API))

2. Follow the **README.md** file in each folder for specific instructions on setting up and running the bot.
