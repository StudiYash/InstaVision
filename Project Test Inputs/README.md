# 📝 Project Test Inputs

Welcome to the **Project Test Inputs** folder! This folder contains a collection of carefully curated text files that serve as **prompts** for testing and evaluating the capabilities of the InstaVision Bot across all individual models. These prompts are designed to showcase the full potential of the bot and can be used as a starting point for your own experiments.

---

## 📂 Folder Contents

This folder includes **10 `text_prompts.txt` files**, each containing a unique test prompt. These prompts are:

1. 🎨 Versatile
2. 🧠 Thought-provoking
3. 🚀 Optimized for showcasing the strengths of each image generation API.

## 🚀 How to Use

1. Open any `.txt` file from this folder to view a prompt.
2. Copy the prompt and use it as input in the InstaVision Bot to test image generation.
3. Compare the results with the examples provided in the model-specific example folders.
