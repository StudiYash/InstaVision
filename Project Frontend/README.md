# Project Frontend 💫

The **Project Frontend** folder is the user interface layer of the **InstaVision** project. It houses all the necessary scripts and resources to create a seamless and interactive experience for users. This folder is designed with a focus on aesthetics, functionality, and ease of use.

## Folder Structure

### 1. Main Page
- **`Main Page.py`**: This script builds the interactive main page UI for InstaVision. Key features include:
  - 🌟 Maximized window view for an immersive experience.
  - 🎨 Dark-themed interface with dynamic logo resizing.
  - 🖼️ Stylish bordered frame for the InstaVision logo.
  - ✨ Hover-responsive buttons for navigation to Image Generation and Image Editing sections.

- **`InstaVision_Logo.png`**: The logo displayed on the main page UI.

- **`README.md`**: Explains the purpose and features of the `Main Page.py` script.

### 2. Image Generation
- **`Image Generation.py`**: This script provides an advanced UI for generating AI-powered images. Key features include:
  - 🖥 Fully responsive design with animated loading bars.
  - 🎨 Customizable dark theme with hover effects.
  - 🖼 Real-time image preview within the application.
  - 📂 Save generated images with a single click.

- **`InstaVision_Logo.png`**: The logo displayed on the Image Generation UI.

- **`README.md`**: Details the features and usage of the `Image Generation.py` script.

### 3. Image Editing
- **`Image Editing.py`**: This script introduces a powerful GUI for AI-based image editing. Key features include:
  - 🖼 Real-time preview of uploaded and edited images.
  - 🛠 AI-powered tools for object removal, enhancements, and more.
  - 📂 Upload and download functionality for images.

- **`InstaVision_Logo.png`**: The logo displayed on the Image Editing UI.

- **`README.md`**: Describes the functionality and usage of the `Image Editing.py` script.

### 4. `InstaVision UI.drawio`
This file served as the blueprint for creating the `.py` files in the **Main Page**, **Image Generation**, and **Image Editing** folders. It outlines the design and functionality of the InstaVision user interface.

This file can be opened by using the official drawio website which can be accessed [here.](https://www.drawio.com/)

---

## Important Note

Each `.py` file in the subfolders uses the **`InstaVision_Logo.png`**. For the scripts to work properly, the **path to the logo file must be updated** in the respective `.py` files. Ensure that the correct file path is provided during setup.

---

## Summary

The **Project Frontend** folder provides:
- A central **Main Page** for navigation.
- Feature-rich interfaces for **Image Generation** and **Image Editing**.
- A blueprint file (`InstaVision UI.drawio`) that guided the development of the UI.

This folder is essential for creating a user-friendly and visually appealing interface for InstaVision, ensuring that users can leverage the power of AI-driven image processing effortlessly.
