# **InstaVision - Interactive Image Editing UI**

This script introduces a **highly interactive and user-friendly GUI** for InstaVision’s **AI-powered image editing** system. Designed with **modern aesthetics**, it integrates an intuitive **Tkinter-based UI** that allows users to edit images using state-of-the-art AI models.

## **Key Features:**
- 🖥 **Full-Screen UI**: The interface launches in **zoomed mode**, ensuring a **seamless** editing experience.
- 🎨 **Customizable Dark Theme**: The UI adopts a **visually appealing dark color scheme**, reducing strain on the eyes.
- 🛠 **AI-Powered Editing**: Select from a variety of **powerful AI-based image enhancement models**.
- 🖼 **Real-Time Image Preview**: Uploaded images are displayed **instantly** within the application.
- ⏳ **Loading Animation**: A **progress bar** appears when images are being processed.
- 🎭 **Dynamic Hover Effects**: Buttons change appearance when hovered, improving **user interaction**.
- 🔄 **Multi-Threaded Processing**: Ensures **smooth UI performance** by processing tasks in the background.
- 📂 **Upload & Download Support**: Easily upload images and save **edited results** with a single click.
- ⚙ **Advanced Settings Panel**: Modify configurations such as **API tokens, banned words, and history management**.
- 📊 **Usage Tracking**: Monitor **monthly and total usage statistics** inside the app.

## **UI Theme & Design:**
This GUI follows a **sleek and modern cybersecurity-inspired aesthetic**, using:
- **Background**: 🖤 Dark Blue (`#002b36`) – Represents **AI technology and security**.
- **Frames & Borders**: 🎭 Deep Gray (`#2A2A3B`) – Adds **sophisticated contrast**.
- **Primary Buttons**: 🔵 Vivid Blue (`#268bd2`) – Provides a **futuristic look**.
- **Hover Effects**: 🔴 Bright Red (`#ec1444`) – Draws attention dynamically.
- **Text Color**: ⚪ White (`#ffffff`) – Ensures **high readability**.

## **How It Works:**
1. 🏁 **Launch the Application** – The UI starts in **maximized mode**.
2. 📤 **Upload an Image** – Select an image for **editing**.
3. 🎛 **Select an AI Editing Model** – Choose from a list of **AI-based editing models**.
4. ✍ **Enter a Prompt** – Provide specific **editing instructions**.
5. ✨ **Apply Edits & Preview** – The AI **processes and previews** the modified image.
6. 📥 **Download the Edited Image** – Save the final result with **one click**.
7. 📊 **View Usage Statistics** – Keep track of **monthly and lifetime AI usage**.

This script acts as the **front-end interface** for InstaVision’s cutting-edge **AI image editing capabilities**, making AI-enhanced creativity **accessible and efficient**! 🚀
