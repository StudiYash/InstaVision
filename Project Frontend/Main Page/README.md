# **InstaVision - Interactive Main Page UI**

This script creates an **aesthetically pleasing and interactive GUI window** for InstaVision, displaying its logo in a **modern, bordered frame** and offering two hover-responsive buttons for navigation. The GUI provides an **intuitive user experience**, making it easy to transition between **Image Generation** and **Image Editing** functionalities.

## **Key Features:**
- 🌟 **Maximized Window View**: The application launches in a **zoomed mode** to ensure a seamless, immersive display.
- 🎨 **Elegant UI Design**: A dark-themed interface with **contrasting colors**, designed to align with InstaVision's branding.
- 🖼️ **Dynamic Logo Resizing**: The InstaVision logo **automatically adjusts** based on screen size, ensuring a **clean and proportional layout**.
- 🔵 **Stylish Bordered Frame**: The logo is enclosed within a **subtle but effective bordered frame**, adding a **professional touch**.
- ✨ **Hover Effects on Buttons**: The **Image Generation** and **Image Editing** buttons change color on hover, offering an engaging and **interactive experience**.
- 🎭 **Smooth User Interaction**: Optimized event handling ensures **responsive UI behavior**, making navigation effortless.

## **UI Theme:**
The GUI follows a **cybersecurity and AI-inspired color scheme**:
- **Background**: 🚀 **Dark Blue (`#002b36`)** – Represents **trust, security, and professionalism**.
- **Borders & Frames**: 🎭 **Deep Gray (`#2A2A3B`)** – A neutral tone for a **clean interface**.
- **Primary Buttons**: 🎨 **Vivid Blue (`#268bd2`)** – Aligns with modern AI-based design.
- **Hover Effect**: 🔴 **Bright Red (`#ec1444`)** – Alerts attention while maintaining **a sleek and modern aesthetic**.
- **Text Color**: ⚪ **White (`#ffffff`)** – High contrast for **maximum readability**.

## **How It Works:**
1. 🏁 **Launch the GUI** – The application starts in **maximized mode**.
2. 🖼️ **InstaVision Logo Appears** – The logo is **dynamically resized** based on the available screen space.
3. 🎮 **Hover & Click on Buttons**:
   - **Image Generation** → Initiates the **image creation process**.
   - **Image Editing** → Opens up **modification tools** for generated images.
4. ✅ **Seamless Navigation** – Users can transition between sections smoothly.

This script serves as the **gateway to InstaVision's powerful image processing features**, providing an engaging and **user-friendly** experience from the very start! 🚀
